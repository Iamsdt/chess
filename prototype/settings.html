How your key is protected

  • Encrypted at rest. AES-GCM via Web Crypto, with a non-extractable key kept in IndexedDB. The page can use it but can never read it out.
  • Sent only to your provider. Straight from your browser to Google. No Chess King server, no proxy.
  • Never in backups. Exports skip it, so sharing a backup file can't leak it.
  • The honest limit. No browser storage can stop malicious code running inside the page. We reduce that risk with a strict Content Security Policy and no third-party scripts.
